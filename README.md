# Assembly Code Vault 🛠️

Welcome to **Assembly Code Vault**! This repository contains a collection of 8086 Assembly language programs, lab tasks, and low-level algorithms written for the EMU8086 / MASM / TASM environment.

---

## 📂 Repository Structure

```text
assembly-code-vault/
├── 01-Basic-IO/
│   ├── hello_world.asm          # Print string to console
│   └── character_io.asm         # Read character and echo output
├── 02-Control-Structures/
│   ├── even_odd.asm             # Check if number is Even or Odd
│   └── largest_number.asm       # Find largest among two numbers
├── 03-Arithmetic-Logic/
│   ├── add_sub.asm              # Addition and Subtraction
│   └── loop_sum.asm             # Sum of first N numbers using Loop
└── README.md
```

---

## 🛠️ Tools & Emulator Used

* **Emulator:** [EMU8086](https://emu8086-microprocessor-emulator.en.softonic.com/) / DOSBox
* **Assembler:** MASM / TASM / EMU8086 Built-in Assembler
* **Architecture:** 8086 Microprocessor Architecture (x86 16-bit)

---

## 🚀 How to Run the Code

1. Download and install **EMU8086** (or setup DOSBox with TASM/MASM).
2. Open any `.asm` file inside EMU8086.
3. Click on **Emulate** (or press `F5`).
4. Click **Run** to execute the code and check the output console.
